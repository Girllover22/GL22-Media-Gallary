# Girllover22 Cinema v0.1.4 — Full Controller Navigation

## Visual upgrade

- Rebuilt premium visual theme
- Modern glass-like navigation and top bar
- Hidden overlay-style scrollbars instead of browser-default bars
- Smooth horizontal wheel scrolling for media rows
- Scroll snapping
- Larger cinematic cards
- Improved shadows, spacing, typography and animation
- Premium modal and player transitions
- Responsive ROG Ally layout
- Controller focus glow

## Controller support

- Xbox-style controller and ROG Ally controls
- D-pad and analogue-stick navigation
- A to open
- B to return
- X for media information
- LB/RB for rapid vertical browsing
- Menu/Start opens Settings
- Controller connection notification

## Storage and privacy

No thumbnail files or video preview files are generated. Chromium runtime storage remains
redirected into the portable application folder and is cleared on a normal exit.
